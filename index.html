Asking for access

Access is the shop's to give. If you work with Taylor'd Wraps, ask the person who introduced you, and give your GitHub username when asked. Never send a password, a code or a key: nobody here will ever ask for one.

How a page gets here

Every page starts in the private room. An owner lists it; a machine copies only the listed pages, after a tripwire that reads every file, including the words inside each PDF. Nobody edits this site by hand. The rule: a public page is never one that a machine or a person has not read.
